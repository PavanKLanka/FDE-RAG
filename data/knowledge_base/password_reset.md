# Password Reset

CloudDesk users can reset their password from the login screen.

To reset a password:

1. Open the CloudDesk login page.
2. Select "Forgot Password".
3. Enter the email address associated with the account.
4. Select "Send Reset Link".
5. Open the password reset email.
6. Select the reset link.
7. Create a new password.

Password reset links expire after 30 minutes.

If the email does not arrive, users should check their spam or junk folder.

Users can request another reset link after the previous link expires.

CloudDesk support agents cannot view or retrieve a user's existing password.

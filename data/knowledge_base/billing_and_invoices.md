# Billing and Invoices

CloudDesk billing is managed from the Billing section of the Admin Console.

Only users with Billing Administrator permissions can view invoices.

To view an invoice:

1. Open Admin Console.
2. Select Billing.
3. Select Invoices.
4. Select the required invoice.

Invoices can be downloaded as PDF files.

CloudDesk generates invoices on the first day of each billing period.

If a payment fails, the billing administrator receives an email notification.

Customers should contact CloudDesk Support if they believe an invoice contains an incorrect charge.

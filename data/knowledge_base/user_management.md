# User Management

Administrators can create, deactivate, and manage users.

To create a user:

1. Open Admin Console.
2. Select Users.
3. Select Add User.
4. Enter the user's name and email address.
5. Assign the required role.
6. Select Save.

Administrators can deactivate users who no longer require access.

Deactivated users cannot log in.

Deactivating a user does not delete historical support tickets created by that user.

# Support Tickets

CloudDesk customers can create support tickets from the Support section.

To create a ticket:

1. Open CloudDesk.
2. Select Support.
3. Select Create Ticket.
4. Enter a subject.
5. Describe the issue.
6. Attach files if necessary.
7. Select Submit.

Customers receive a confirmation email after submitting a ticket.

Customers can view ticket status from the My Tickets page.

Ticket statuses include:

Open
In Progress
Waiting for Customer
Resolved
Closed
